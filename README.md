# حاسبة كميات المسبح

صفحة عربية لحساب مياه وتشطيب مسبح مستطيل، دون تثبيت أي مكتبات.

## الاستخدام

افتح `index.html` في المتصفح، وأدخل الطول والعرض والعمق الضحل والعميق بالمتر، ستظهر النتائج تلقائيًا عند تغيير أي قيمة. ويمكن أيضًا الضغط على «احسب الكميات».

تفترض الحاسبة أرضية تميل بانتظام على امتداد الطول وجدرانًا رأسية. القيم الافتراضية: 6.00 × 3.50 متر، وعمق من 1.00 إلى 1.60 متر.

النتائج تشمل متوسط العمق وحجم المياه بالمتر المكعب واللتر، ومساحة الأرضية المائلة والجدران وإجمالي التشطيب بالمتر المربع. لا تشمل الدرج والمقاعد أو هدر المواد.

## ملفات المشروع

- `index.html`: الواجهة العربية.
- `styles.css`: التنسيق المتجاوب مع الهاتف.
- `calculator.js`: المعادلات والتحقق من المدخلات.

للتشغيل عبر خادم محلي اختياري، من مجلد المشروع:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

لإجراء اختبارات الحساب باستخدام Node.js:

```sh
node --test calculator.test.js
```

اختبار الواجهة الاختياري يتطلب Playwright ومتصفح Chromium، ولا يلزمان للاستخدام العادي:

```sh
node --test calculator.test.js browser.test.js
```

يمكن تحديد مسار Chromium عبر المتغير `CHROMIUM_PATH`. اختُبرت الواجهة فعليًا على عرض الهاتف والكمبيوتر، مع التحديث التلقائي ومعالجة المدخلات غير الصحيحة.
